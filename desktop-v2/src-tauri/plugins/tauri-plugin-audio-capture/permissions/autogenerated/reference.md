## Default Permission

Default permissions for the audio capture plugin

#### This default permission set includes the following:

- `allow-list-devices`
- `allow-start-recording`
- `allow-stop-recording`
- `allow-get-capture-state`
- `allow-probe-system-audio`
- `allow-probe-live-capture`
- `allow-request-system-audio-permission`
- `allow-list-local-sessions`
- `allow-get-local-segments`
- `allow-retry-sync-now`
- `allow-retry-all-failed`
- `allow-delete-local-session`
- `allow-delete-all-unsynced`
